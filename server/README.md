# Home Assistant Demo Environment

This directory contains a script and configuration to quickly spin up a local Home Assistant instance running in **Demo Mode** with several preconfigured **Virtual Entities** for testing, automation design, or API development.

## Prerequisites

- **Python 3.x** installed (required to run the orchestrator script `run_demo.py`).
- **Docker** (required):
  - The orchestrator script starts Home Assistant from the official Docker image when Docker is available and running.
  - If Docker is not available, the script exits with a clear error message and asks you to start Docker first.

---

## Getting Started

Open a terminal in this directory and use the `run_demo.py` utility script to manage the lifecycle of your Home Assistant demo.

### 1. Start the Demo
```bash
python run_demo.py start
```
*This command checks that Docker is running, then pulls the stable Home Assistant image and boots the container mapping port `8123`.*

After launching, open your browser and navigate to:
**[http://localhost:8123](http://localhost:8123)**

> [!NOTE]
> On the first start, Home Assistant requires creating an initial owner user account. Enter any username and password of your choice to proceed to the dashboard.

### 2. Check the Status
```bash
python run_demo.py status
```
Prints whether the Docker container is running.

### 3. View Logs
```bash
python run_demo.py logs
```
Tails the live server logs (press `Ctrl+C` to stop streaming).

### 4. Stop the Demo
```bash
python run_demo.py stop
```
Stops and removes the Docker container.

### 5. Clean up
```bash
python run_demo.py clean
```
Stops the environment and resets the local Home Assistant config files while preserving your `configuration.yaml` file.

## Included Test Entities

In addition to the default demo entities (lights, media players, climate controls, vacuum, locks) generated by the `demo:` integration, the instance is pre-seeded with the following virtual entities defined in [configuration.yaml](file:///C:/Users/david/home-assistant-demo/config/configuration.yaml):

### Input Helpers (Interactive)
- **`input_boolean.main_power_switch`** (`Main Power Switch`): A toggle switch.
- **`input_boolean.living_room_light`** (`Living Room Light`): A toggle switch.
- **`input_number.power_level`** (`Power Level`): A slider ranging from `0` to `100`.
- **`input_select.hvac_mode`** (`HVAC Mode`): Dropdown menu with options: `Normal Mode`, `Eco Mode`, `Boost Mode`.
- **`input_text.system_status_text`** (`System Status Text`): A text box for inputting arbitrary text.

### Reactive Template Sensors (Calculated)
- **`sensor.main_power_meter`** (`Main Power Meter`): Calculates a virtual power reading based on other entities:
  - If `Main Power Switch` is **Off**, power is `0.0 W`.
  - If `Main Power Switch` is **On**, power is `10.5 W` + (`Power Level` value * `1.5 W`).
- **`sensor.hvac_operating_state`** (`HVAC Operating State`): Displays:
  - `Standby` if `Living Room Light` is **Off**.
  - The current value of `HVAC Mode` + ` - Active` if `Living Room Light` is **On**.
